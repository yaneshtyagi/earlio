## Which manual do I need?

- **Everyone** reads *Getting started* first.
- Then read the manual for **your organisation type**. Each manual opens with a table of the roles in that organisation and what each can do, so you can skip to the sections for your role.
- Looking for something specific? Use the [subject index](index.md#subject-index) or the [task index](index.md#task-index).

## About the screenshots

The screenshots come from Earlio's demo environment (version 0.1): fictional organisations, simulated banks, insurer, exchange rates and payments, and a virtual clock set to 2 November 2026. Every page there carries a yellow *Simulated environment* banner, which production does not show. Screen captures are 1360 px wide and stored as WebP under [`images/`](images), one folder per organisation type.
