# ADR-002: Row-level security tenancy
Shared database; every tenant table carries `org_id` (or supplier/buyer/bank columns) with RLS policies using `app.org_id()` and `app.is_platform()`, set with `set_config(..., true)` per transaction by `Db.tx`. The application connects as a non-owner role (`earlio_app`) so RLS applies. RLS defends against missing filters; it is not a defence against a compromised application process. Cross-tenant platform access is explicit (`platformCtx`) and audited. Organisation rows are readable by all (counterparty names) with sensitive columns projected out in the API.
